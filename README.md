# ayenewdemeke.me

Source for the academic website of Ayenew Yihune Demeke, served at https://ayenewdemeke.me via GitHub Pages.

The site is built on the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template (MIT license; see `LICENSE`). See `CLAUDE.md` for the site layout, the procedure for adding a paper, and local build instructions.
